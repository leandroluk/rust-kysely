# rust-kysely

Type-safe SQL query builder and runner for Rust, ported directly from Kysely (TypeScript), without macros.

## Configuration
Traceability: on
Primary Language: Rust (2021/2024 edition)
Target Dialect: PostgreSQL (initial focus)
Upstream Source: https://github.com/kysely-org/kysely
Philosophy: 100% Macro-Free, Pure Rust Fluent API, Full AST Representation, Dialect Compilers, Extensible Execution Engine.
