# Spec: 08 — Plugin Architecture & Built-in Plugins

## Summary
Implements the plugin architecture and built-in plugins for `rust-kysely`, ported from upstream `src/plugin/`. Provides the `KyselyPlugin` trait with hooks for AST transformation before compilation (`transform_query`) and result interception before return (`transform_result`). Delivers built-in plugins including `CamelCasePlugin` (mapping between Rust/API camelCase and database snake_case columns), `DeduplicateJoinsPlugin` (pruning duplicate joins added across dynamic query branches), and `WithSchemaPlugin` (applying a default PostgreSQL schema to unqualified table names).

## Requirements
- REQ-PLUG-001: Implement `KyselyPlugin` trait defining `transform_query(node: RootOperationNode, query_id: QueryId) -> RootOperationNode` and `transform_result(result: QueryResult, query_id: QueryId) -> QueryResult`.
- REQ-PLUG-002: Implement `CamelCasePlugin` transforming identifier names in the AST (camelCase to snake_case for column/table nodes) and transforming row keys in `QueryResult` (snake_case to camelCase).
- REQ-PLUG-003: Allow `CamelCasePlugin` configuration options (e.g. preserve underscore prefix, custom snake_case mapper).
- REQ-PLUG-004: Implement `DeduplicateJoinsPlugin` inspecting `JoinNode` elements on `SelectQueryNode` and removing identical duplicate joins generated by dynamic filter builders.
- REQ-PLUG-005: Implement `WithSchemaPlugin` prefixing unqualified table references with a designated PostgreSQL schema name (e.g. `"my_schema"."users"`).
- REQ-PLUG-006: Support plugin registration on `Kysely` instantiation and per-query chaining via `.with_plugin(plugin)`.

## Affected Components
- `src/plugin/` — `KyselyPlugin`, `CamelCasePlugin`, `DeduplicateJoinsPlugin`, `WithSchemaPlugin`
- `src/query_executor/default_query_executor.rs` — Plugin execution pipeline

## Out of Scope
- Third-party driver plugins (drivers implement the `Driver` trait directly).
- Mutating queries after compilation (plugins operate on AST `OperationNode`).
